## Fonts

`fonts/` contains fallback Bootstrap 3.4.1 Glyphicons Halflings fonts (`glyphicons-halflings-regular.*`) for UrqW builds prior to `2026-11-08`, which referenced them in `dist/style.min.css` without bundling them in upstream release archives:
- `fonts/glyphicons-halflings-regular.eot`
- `fonts/glyphicons-halflings-regular.svg`
- `fonts/glyphicons-halflings-regular.ttf`
- `fonts/glyphicons-halflings-regular.woff`
- `fonts/glyphicons-halflings-regular.woff2`
